Privacy Policy — ThisIsExperience Ads CLI

Effective date: 14 October 2026

ThisIsExperience Ads CLI ("the tool") is an internal command-line tool made and used only by ThisIsExperience ("we"). It is not offered to the public. It signs in with Google so that we can work with our own Google Ads account and Google Analytics properties.

Google data the tool accesses. With the permissions you grant on Google's sign-in screen, the tool uses:

  • Google Ads API: our campaigns, ad groups, ads, budgets, targeting and their performance reports (impressions, clicks, installs, cost). The tool can also change our own campaigns, for example pause a campaign or change its budget, when we run such a command.
  • Google Analytics Data API and Admin API (read-only): reports and configuration of our GA4 properties, such as event counts and user metrics for our games.

How the data is used. Only to report on and manage our own advertising and to understand how our games are played. The data is not used for advertising, not sold, and not used to build user profiles. We do not use it to develop, improve or train generalized AI or machine-learning models.

Where it is stored. The tool runs on our own computer. The sign-in tokens are stored there in files only our user account can read. Reports are shown on screen or saved as local files. There is no server or database for the tool.

Sharing. We do not share, sell or transfer this data to anyone, except to the service providers that run the tool for us. We may analyse reports with an AI assistant (Claude, by Anthropic) running on our computer. Anthropic processes that data on our behalf.

Limited Use. The tool's use and transfer of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Removing access. Access can be removed at any time at myaccount.google.com/permissions. Deleting the token files on our computer also removes the tool's stored access.

Changes. If this policy changes, the new version will be posted at this address with a new effective date.
